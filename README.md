# Momentmaker

A CliprAI-inspired, independently branded manual video clipper. Runs as a static website without a server, accounts, or uploading videos.

## Host on GitHub Pages
1. Put index.html and this README at the root of a GitHub repository.
2. In the repository, open Settings > Pages. Under Build and deployment, choose Deploy from a branch, then select the main branch and / (root), and Save.
3. Open the GitHub Pages URL shown in Settings > Pages after deployment completes.

## Use
Select a local browser-supported video (up to 500 MB). Choose start/end times (maximum 120 seconds), format, crop or fit, optional caption and audio. Click Export WebM, keep the tab visible while recording, and download the clip from the session library before leaving. The source video and clips are processed locally in your browser.

## Important limits
This is not a full CliprAI replacement: there is no AI highlight finding, automatic transcription, face tracking, import from online URLs, MP4 export, or persistent cloud library. The crop is centered; caption text is static for the entire clip. WebM recording and playback require browser codec support; Chrome/Chromium was tested but individual phones and Safari were not. WebM duration metadata can be missing, affecting seeking in some players. Use only videos you have permission to edit and share.
